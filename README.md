# EQUIPO BASKET · Producto 3 · Interfaz móvil

Aplicación móvil de EQUIPO BASKET hecha con **React Native** (Expo) para la asignatura FP.451. Se conecta a la misma base de datos de **Cloud Firestore** que la aplicación web del Producto 2 y tiene tres ventanas: listado de la plantilla, ficha del jugador y reproductor de vídeo.
